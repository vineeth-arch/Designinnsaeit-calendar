Booking emails: design gallery

Generated from the real email renderer, so these match what is sent. Figma is the design intent; these HTML emails are the source of truth for what email clients can do.

Email rules:
  • Table layout only. No CSS grid or flex, no JavaScript, no web fonts, no SVG images.
  • Max width 600px; every two-cell row must stay readable at 320px because the layout scales down rather than stacking.
  • Images are PNG, JPG or GIF hosted at ${WEBAPP_URL}/emails/. Every image needs meaningful alt text.
  • Nothing essential may live only in an image: images are blocked by default in Outlook and some Gmail setups.
  • Animated GIF: under about 150 KB, must look right frozen on its first frame (Outlook desktop shows only frame 1), play once and hold.
  • Dark mode is forced light (color-scheme: light only). Design with opaque backgrounds.
  • Total email HTML must stay under 100 KB (Gmail clips at 102 KB).
  • Outlook desktop shows square corners and ignores some padding on links; the design must still read correctly.
  • Contrast: white on #FF006C is about 4.3:1, so use it only for bold or large text (16px bold or bigger).
  • Subject lines are unchanged and are not part of this design.

Edge cases

State: no-link

Location is an address or phone number: no Join button, Manage booking caption, location shown in the stub.

State: long-title

120+ character event title, 90 minute event, no intake answers.

State: images-blocked

All images removed. The card must still read correctly.

Also cover

  • actions-0-to-4: The action grid shows 0 to 4 buttons; an odd last one spans both columns. Cover 4, 3, 2, 1 and 0.
  • intake-none-or-many: Stub with no details, or with several intake answers.
  • 24h-clock: Recipient prefers a 24-hour clock: time shows as 09:00.
  • mobile-375: Every email at 375px width.
